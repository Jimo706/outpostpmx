v2026.08.2-beta
IMPLEMENTED
(#112) Added Base64 message encoding and tag support.
(#148, #149) Enhanced the About OutpostX information and updated OutpostX form labeling.
(#158) Received messages marked Urgent are now displayed with the entire message-list row in red text.

FIXED
(#41) Forwarding a bulletin now defaults the forwarded message type to Private, rather than creating another bulletin.
(#67) Editing and saving a Queued message now changes its state back to Draft, rather than leaving it queued.
(#134) Fixed Linux Open Data Folder failures in PyInstaller builds by launching the system file manager using a cleaned external-process environment. Verified on openSUSE 16.0 with Plasma/Wayland, Plasma/X11, LXQt, Openbox, and Xfce.
(#147) Made Preferences > Copy functionality consistent across all configuration areas.
(#153) Fixed Delivery Receipt handling so receipts are not sent for downloaded bulletins.
(#154) OutpostX no longer attempts to delete downloaded bulletins from the BBS, regardless of who sent them.
(#155) Downloaded bulletins are now correctly identified as Bulletin messages rather than Private messages.

CHANGED
(#157) Changed the main message list 'Dir' column to 'Type'. Message types are displayed as B for Bulletin, NTS for NTS traffic, and blank for Private messages.

KNOWN ISSUES
* Send/Receive: Session dialog header fields appear blank.
* macOS Apple Chipset: Application packages are not yet code signed.
* Scripting: Not yet implemented.
* Forms: ICS-213 support is planned for a future release.
