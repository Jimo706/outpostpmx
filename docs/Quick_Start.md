2. Quick Start Guide

"I installed it. Now what?"

This should be intentionally short—perhaps 10–15 pages.

Example flow:

Install OutpostPMX.
Create your Station Profile.
Create your Interface Profile.
Create your BBS Profile.
Connect to a BBS.
Download mail.
Read a message.
Compose a reply.
Send the reply.
Congratulations—you've used OutpostPMX.

That's it.

The goal is to get someone successful in 30 minutes, not teach every feature.
